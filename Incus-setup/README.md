Incus-setup is used to help and assist in the setup of Incus cotainers primarly, otherwise most of these scripts can be used on any standard debian server.

<br>

> ## General Summary of contents
> - `instance-setup.sh` Does the basic setup for a container,eg  updates.
> - `systemd-generator` Sets up a systemd file for a service.

## How to setup

run 
```bash
curl https://raw.githubusercontent.com/haywik/linux-public/refs/heads/main/Incus-setup/instance-setup.sh | bash
```
